Post-quantum encrypted messaging on XDC

XDC PQOnchain encrypts messages with ML-KEM-768, the key-encapsulation standard NIST published as FIPS 203, and sends them as XDC transaction data. Keys are created and used only in your browser.

A public chain keeps data forever. “Harvest now, decrypt later” attacks store encrypted data today to crack once quantum computers mature. ML-KEM is designed to hold up against them.

02 Directory

Live tools

Web apps open straight in your browser. Self-hosted tools are installed from GitHub on your own server or GitHub account.

Node & validator operations

Set up, monitor and keep your infrastructure earning.

  • XDC Secure RPC & WSS

    Self-hosted

    An installer for any XDC node operator, including Plugin RPCaaS. Sets up a hardened XDC node on Mainnet or Apothem with private RPC and WebSocket endpoints that only whitelisted IPs can reach.

    One-script setup with Nginx and TLS. The included scripts manage the whitelist for you. Prefer not to do it yourself? Guided setup is US$90, or a full install US$200.

    View on GitHub Have it installed for you

  • XDC Sentinel

    Self-hosted

    Get a phone alert when one of your XDC nodes goes offline, a reminder every 2 hours until it’s back, and a daily message confirming everything is running.

    Notifications on iOS and Android. Free to self-host, or hosted for you at US$40 per node a year with a 30-day free trial.

    View on GitHub Hosted option

  • XDC Tycoon

    Self-hosted

    Watch your masternode owner addresses and get notified when their status changes (masternode, standby, slashed and so on) and when educational reward top-up payments arrive.

    Notifications on iOS and Android. Free to self-host, or hosted for you at US$40 per node a year with a 30-day free trial.

    View on GitHub Hosted option

  • XDC Epoch Notifier

    Self-hosted

    Get a phone notification every morning with the epoch rewards each of your masternodes earned, adjusted for your own transfers and fees. If a node earned nothing, or the check couldn’t run, you get a loud alert instead.

    Notifications on iOS and Android. Free, with no server needed: it runs on your own GitHub account.

    Set it up Source on GitHub

  • Masternode Epoch Rewards Calculator

    Web app

    Work out the epoch rewards an address earned as a masternode over a time period you choose, inferred from on-chain data. Useful for tax time and reporting.

    Open calculator

Payments & commerce

Take payments, issue receipts and keep records.

  • XDC Proof

    Web app

    Turn an XDC payment into a PDF receipt with a QR code that links to the transaction, so anyone can verify it. Make one at a time or a whole batch, for invoices, bookkeeping or trade finance.

    Add your own branding to each receipt. Runs entirely in your browser.

    Create a receipt

  • XDC ShopBot

    Telegram bot

    A Telegram shop that sells digital products for XDC and delivers them automatically. Made for small sellers who want to run an online shop without advanced coding.

    Free and open source. Try the demo before setting up your own. A larger version 2 is in development.

    Try the demo bot Source on GitHub

  • FuelSharp NSW

    Web app

    Find the cheapest fuel near you in NSW at the price you’ll actually pay. Live prices from the NSW Government’s FuelCheck data, with your own discounts taken off, shown in AUDD, XDC or USDC.

    Installs on your phone like an app. NSW only. Your discounts stay in your browser.

    Find cheap fuel Source on GitHub

Security & post-quantum

Encrypt privately and sign safely.

  • XDC PQOnchain

    Web app, post-quantum

    Send post-quantum encrypted messages on the XDC Network. Generate an ML-KEM-768 keypair, connect MetaMask, send messages as transaction data, and decrypt anything sent to you from its transaction hash.

    Uses ML-KEM-768 (NIST FIPS 203) with AES-256-GCM. Everything runs in your browser, with no servers involved.

    Open app Source on GitHub

  • XDC Send Offline Helper

    Web app

    Prepare transactions for an offline wallet and broadcast them once signed. Enter your address to get the transaction details, scan a QR code, or paste a signed transaction to send it to the network.

    Your private key never comes near this page. Works in a desktop or mobile browser.

    Open app

    A neutral map of the XDC Network ecosystem in three views: a directory of 130+ tools, apps and services; a reading library of developer guides from across the ecosystem; and live status for every public XDC RPC endpoint.

    Community-maintained: anyone can add a project, guide or RPC endpoint by pull request. Listing is for discovery, not endorsement.

    Ecosystem directory Reading library RPC status

    Reads the public stats feed and the chain straight from your browser. Pin your own nodes to keep them at the top.

Node & validator operations

  • XDC Offline Signer

    In development

    Move XDC and tokens, and carry out masternode operations, with a private key kept on an air-gapped device. The phone and the offline laptop exchange data only through QR codes.

  • XDC Validator Stake Desk

    In development

    Masternode stake management directly against the XDC validator contract, for masternode operators and institutional validators. Works with MetaMask or produces unsigned transactions for offline signing.

Payments & commerce

  • XDC POS

    In development

    A point-of-sale app that installs on any phone. Customers pay by QR code in XDC, USDC, AUDD or other tokens, with receipts, refunds, loyalty, a customer display and CSV exports for Xero, MYOB or QuickBooks. Payments go straight to the merchant’s wallet.

  • Fair Tickets

    In development

    Phone tickets for fairs, fetes and fundraisers. Families buy tickets at the booth with cash or card, then show a code at any stall. Organisers get exact totals, house leaderboards and a live tally screen.

  • XDC ShopBot v2

    In development

    A payment button any website can use, including static sites: customers click through to pay in Telegram in XDC, AUDD, USDC or any XRC-20 token, and receive PDF tax invoices. Sellers get sales reports and accounting exports.

  • SHKeeper integration

    Awaiting review

    XDC Network support for SHKeeper, the open-source, self-hosted crypto payment gateway. Submitted to the SHKeeper project and waiting for their team’s review.

Security & post-quantum

  • XDC PQChat

    In development

    A post-quantum encrypted messenger on XDC with conversations, contacts and full recovery, using ML-KEM-768 encryption and ML-DSA-44 sender authentication. Designed with company-run sidechains in mind, for verifiable internal message history.

  • Hybrid post-quantum signing

    Planned

    Sign documents with ML-DSA (NIST FIPS 204) alongside a standard ECDSA signature, and anchor the document’s hash on XDC. An independent implementation, not an official XDC standard.

  • Quantum exposure scanner

    Planned

    Flags addresses whose public key is already visible on chain because they have sent a transaction, starting with masternode and treasury addresses, so owners can plan ahead.

Agents & machines

  • XDC FieldMedic

    In development

    An autonomous node-operations agent for XDC RPC endpoints. It spots errors and lag as they happen and runs repairs, keeping downtime to a minimum.

  • Open data feed

    Planned

    RPC health, epoch rewards and ecosystem data published as open JSON files, so AI agents and scripts can read them directly. Free, with no API key.

  • MCP server

    Planned

    Lets AI assistants query XDC node health, masternode rewards and payment receipts through the Model Context Protocol. Runs on your own computer.

  • Machine wallet reference kit

    Planned

    An open kit for a Raspberry Pi or ESP32: the device signs its own telemetry, anchors it on XDC, and pays or gets paid in USDC or AUDD within spending limits you set.

04 About

About XDC Outpost

XDC Outpost is an independent, community-built project run by s4njk4n, part of the XDC community since July 2017. Since 2021 I’ve been contributing on the technical side: tutorials and technical documentation for node operators and masternode owners, and the tools on this site.

Most of the tools started with a gap I noticed: something people kept asking for, or a job that was harder than it needed to be. I build the fix, test it, and publish it here with its source code.

You can read my guides on xdc.dev and Medium, many of them collected in the XDC Atlas reading library.

Independent

XDC Outpost is built and run independently. It isn’t operated by the XDC Foundation or XinFin, and it doesn’t speak for them; decisions about these tools and what this site says are my own. “XDC” refers to the network these tools are built for. Where a tool follows a draft or proposed standard, it says so and is an independent implementation.

  • Free and open sourceEvery tool is MIT licensed, and you can read the code before you use it.
  • Your keys stay yoursWeb apps run entirely in your browser. Self-hosted tools run on your own server or GitHub account. Payment tools send funds straight to your wallet and never hold them.
  • No accounts, no cookiesThis site counts visits with GoatCounter, which doesn’t use cookies or collect personal data.
  • Clearly labelledEvery tool is marked Live, In testing, In development or Planned, so you know what you can rely on today.

Need a hand?

The tools are free and always will be. If you’d rather not set them up yourself, or you need something built for your own project or organisation, I can help with:
